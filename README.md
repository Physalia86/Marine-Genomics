# Marine Genomics Course

Welcome to the **Marine Genomics** course repository.

This course provides a practical and conceptual introduction to marine genomics, from genome resources to population and seascape genomics, with a strong emphasis on hands-on data analysis using real-world datasets.

---

## 🧭 Course Schedule

### Day 1 — Introduction to Marine Genomics & Genome Resources  
**1:00–6:00 PM (Berlin time)**

- Course overview and introductions  
- Introduction to marine genomics: opportunities and challenges  
- Sequencing technologies and data analysis  

**Hands-on session:**
- Exploring genome assemblies  
- Downloading and assessing genomes (BUSCO, QUAST, etc.)  
- Checking genome annotations (GFF files)  
- Evaluating reference genome quality (size, masked/unmasked regions, completeness, usability considerations)

---

### Day 2 — Sequencing Data Processing and Variant Calling  
**1:00–6:00 PM (Berlin time)**

- Read alignment and genome references  
- Variant calling pipelines (SNPs/indels)  
- Filtering and preparation of datasets for downstream analyses  

**Hands-on session:**
- Quality control, trimming, and mapping of NGS data  
- Practical variant calling workflows  

---

### Day 3 — Population Genomics Approaches  
**1:00–6:00 PM (Berlin time)**

- Introduction to population genomics concepts  
- Genetic diversity, population structure, and demographic inference  

**Hands-on session:**
- Population genomics analyses using marine datasets  

---

### Day 4 — Seascape Genomics: Linking Genomics with Environmental Data  
**1:00–6:00 PM (Berlin time)**

- Environmental data collection and key parameters  
- Data integration for seascape genomics  
- Case studies in marine systems  

**Hands-on session:**
- Working with environmental datasets  

---

### Day 5 — Integrative Analyses: Environment–Genomics Associations  
**1:00–6:00 PM (Berlin time)**

- Statistical approaches linking genomic variation and environment  
- Seascape genomics models and tools  

**Hands-on session:**
- Association analyses  
- Interpretation and discussion of results
